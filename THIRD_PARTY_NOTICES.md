# Proyectos externos

La selección no incluye código, binarios ni modelos de los siguientes proyectos.
Sus nombres describen dependencias o integraciones previstas, no patrocinio ni
autoría sobre ellos. Revise las licencias de las versiones que instale.

| Proyecto | Relación | Fuente oficial |
| --- | --- | --- |
| Python | Intérprete y biblioteca estándar. | https://www.python.org/ |
| SQLite / FTS5 | Estado e índice a través de sqlite3. | https://sqlite.org/fts5.html |
| llama-swap | Servicio compatible previsto por el cliente. | https://github.com/mostlygeek/llama-swap |
| llama.cpp | Motor mencionado en el diseño; no incluido. | https://github.com/ggml-org/llama.cpp |
| aria2 | Ejecutable opcional de descargas. | https://github.com/aria2/aria2 |
| PyYAML | Parser opcional de manifiestos. | https://github.com/yaml/pyyaml |
| Requests | Consultas opcionales del gestor de descargas. | https://github.com/psf/requests |
| NumPy | Aceleración vectorial opcional; existe ruta Python. | https://numpy.org/ |
| Git | Historial local opcional de notas. | https://git-scm.com/ |
| Heretic | Wrapper original excluido de la publicación. | https://github.com/p-e-w/heretic |
